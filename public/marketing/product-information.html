🚗 FC Manager

Freedom Camping Compliance Management System - Technical Information Document

New Zealand Local Government & Security Company Application

📋 System Overview

FC Manager is a field operations management system designed for New Zealand councils and security companies to enforce Freedom Camping Act 2011 regulations. The system combines ALPR (Automatic License Plate Recognition), GPS tracking, compliance automation, and evidence management.

🏗️ Architecture

Cloud-based Progressive Web App (PWA) built on React + TypeScript with Supabase backend (PostgreSQL, real-time subscriptions, edge functions).

📱 Deployment

Web application accessible via modern browsers on desktop, tablet, and mobile devices. Installable as native-like app on iOS and Android.

🔐 Security

Row-level security (RLS) policies, invite-only user management, role-based access control, and organizational data isolation.

🌐 Hosting

Currently deployed at fcmanager.co.nz with automatic HTTPS, CDN distribution, and 99.9% uptime SLA.

👥 User Management & Access Levels

⚠️ Invite-Only System Users cannot self-register. All accounts must be created by administrators through the secure user management interface with email/password credentials.

Role Hierarchy

Role Access Level Primary Responsibilities Key Permissions
Master System-Wide System administration, multi-organization oversight, full data visibility Create organizations, view all data across organizations, system diagnostics, data recovery, master-level configuration
Admin Organization Organization management, user administration, compliance oversight Create users, manage patrols, review breaches, approve enforcement actions, configure zones, run reports
Officer Field Operations Vehicle scanning, incident reporting, patrol execution Scan plates, create incidents, record observations, access Field Officer Portal
Admin Officer Dual Role Field operations + limited administrative tasks All officer permissions + patrol management, incident review (cannot self-approve)

Master Admin Capabilities

The Master role is designed for system administrators and platform operators who need visibility across all organizations:

  • Multi-Organization Management: View and manage data from all organizations in a single interface with organization selector
  • System Diagnostics: Access database integrity checks, performance monitoring, and error log analysis
  • Data Recovery: Emergency data recovery tools for restoring deleted records and resolving data inconsistencies
  • Global Configuration: System-wide settings, feature flags, and deployment management
  • Audit Oversight: Complete audit trail visibility across all organizations for compliance and security reviews
  • User Administration: Create and manage users across any organization, including password resets and role changes

User Creation Process

Step 1: Admin/Master logs into Admin Portal → User Management
Step 2: Click "Create User" → Enter email, name, role, organization assignment
Step 3: System sends invite email with temporary password
Step 4: New user logs in → Prompted to change password on first login
Step 5: User assigned to appropriate portal (Field Officer Portal or Admin Portal based on role)

⚙️ Core System Features

1. Automatic License Plate Recognition (ALPR)

  • Plate Recognizer API integration optimized for New Zealand plates
  • Mobile camera capture with auto-focus and zoom controls
  • AI-powered vehicle make/model/color detection
  • Self-contained sticker detection (green and blue stickers)
  • Manual entry fallback for poor lighting or damaged plates
  • File upload support for processing existing photos

2. GPS Tracking & Evidence Integrity

  • Real-time GPS coordinate capture with accuracy indicators (Good ≤50m, Fair ≤100m, Poor >100m)
  • GPS data stored in database with all observations
  • Photo hash calculation (SHA-256) for tamper detection
  • Timestamp recording in NZ timezone (Pacific/Auckland)
  • Immutable audit trail for all enforcement actions
  • Photo retention policies (standard 90 days, court-ready permanent, custom policies available)

3. Compliance Automation

  • Automatic compliance evaluation against zone-specific rules (nights per month, consecutive stays, self-contained requirements)
  • Consecutive-day detection algorithm using GPS location + patrol evidence (first observation = intent, second consecutive day in same location = overnight camping proof)
  • Monthly stay tracking per vehicle per zone (calendar month reset)
  • Freedom Camping Act exemption logic for confirmed homeless vehicles
  • Real-time breach detection with automatic alert generation
  • After-hours violation detection (configurable allowed hours per zone)

4. Enforcement Workflows

  • Officer-First Workflow: Field officers can immediately issue warnings, notices, and tow requests
  • Admin-First Workflow: Officers record breach advisories → Admin reviews and approves → Official enforcement action created
  • Breach alert management with assigned officer tracking
  • Enforcement action types: verbal warning, written notice, breach advisory, tow request, compliance check
  • Delivery confirmation tracking (delivered, acknowledged, pending)
  • Follow-up scheduling and resolution tracking

5. Field Officer Portal (Mobile-Optimized)

  • 6-Tab Navigation: Dashboard, Scan, Zoom Scan, Reports, Offline Queue, History
  • Dashboard: Current zone/patrol, GPS status, today's scan stats, investigation assignments, enforcement jobs
  • Scan Mode: Single vehicle capture with full details collection
  • Zoom Scan Mode: High-speed scanning with persistent queue (20+ vehicles without interruption)
  • Offline Queue: View pending scans when offline, manual sync trigger, storage usage monitoring
  • Reports: Incident reports created by officer with status tracking
  • GPS location display with accuracy badge
  • Network status indicator (online/offline)
  • Dark mode support with automatic detection

6. Admin Portal (Desktop/Tablet)

  • Operational Section: Urgent Follow-Ups (requires attention queue), Organization Overview (BI-style dashboard), Officer Welfare Hub (GPS tracking + alerts), Patrol Management, Investigation Jobs, Bulk Scan Review
  • Enforcement Section: Incident Reports (court-ready approval workflow), Enforcement Hub (comprehensive action tracking), Flagged Vehicles (problem vehicle registry)
  • Analytics: Compliance trends, zone performance breakdown, officer activity reports, exportable leadership packs
  • Management: Data Management Hub (vehicles, zones, matrices, persons, cleanup tools), Settings Hub (users, organizations, zones, compliance policies, privacy controls)
  • Help & Support: Comprehensive documentation, feature guides, troubleshooting
  • Documents (Master Only): Product information, system documentation

7. Homeless Support & FC Act Compliance

  • Homeless status tracking (claimed, confirmed, declined)
  • Admin approval workflow for homeless verification
  • Freedom Camping Act automatic exemption for confirmed homeless vehicles
  • Person records management (separate from vehicle records)
  • Person observations table linking individuals to vehicles and zones
  • Homeless notes and social service integration points

8. Officer Safety & Welfare

  • Real-time GPS tracking with 30-second ping intervals
  • Inactivity detection with auto-logoff warnings (configurable thresholds)
  • Welfare alerts escalation (officer warning → admin notification → critical escalation)
  • Investigation exception mode (prevents false alarms during long investigation jobs)
  • Manual welfare check triggers
  • Live officer location map in Admin Portal
  • Emergency escalation protocols

9. Investigation Jobs Management

  • Job types: Homeless Occupation, Abandoned Vehicle, Unauthorized Structure, Noise Complaint, Environmental Hazard, Welfare Check, Trespass, Other
  • Task assignment to field officers with priority levels (urgent, high, medium, low)
  • GPS-tagged briefing notes and location details
  • Evidence photo upload with metadata tracking
  • Investigation findings reports (visit date, structures/vehicles found, persons contacted, recommendations)
  • Follow-up tracking and completion workflow

10. Data Management & Import

  • Historical Data Import: AI-powered batch processing (250 records/batch) with automatic zone matching and date format detection
  • Compliance Recalculation: Recalculate all compliance results when zone rules change (zone-specific, organization-wide, or date-range scoped)
  • Data Cleanup: Identify and resolve duplicate observations, orphaned records, missing GPS data, invalid zone assignments
  • Zone Corrections: Auto-detect and fix observations assigned to wrong zones based on GPS coordinates
  • Vehicle Enrichment: AI-powered vehicle details enrichment from photos (make/model/color/year detection)

🔧 Technical Specifications

Frontend Stack

React 18.3, TypeScript 5.5, Tailwind CSS 3.4, React Router 6.x, React Query 5.x, React Hook Form + Zod validation

Backend Stack

Supabase (PostgreSQL 15, Row-Level Security, Realtime subscriptions, Edge Functions runtime)

Integrations

Plate Recognizer API (ALPR), OnSpace AI (vehicle analysis), Stripe (future payments), Supabase Storage (photo hosting)

Database

40+ tables, 30+ functions/triggers, comprehensive RLS policies, automatic audit logging, indexed queries

Database Architecture Highlights

  • canonical_vehicles: One record per plate number globally (profile photos, homeless status, flagged vehicles)
  • vehicle_observations_v2: All vehicle sightings with GPS, compliance snapshots, breach detection
  • compliance_results: Authoritative compliance evaluations linked to zone matrix versions (audit trail for drift detection)
  • zone_compliance_matrix: Versioned zone rules with historical tracking (enables compliance recalculation)
  • breach_alerts: Automatic breach notifications with assignment and resolution workflows
  • enforcement_actions: All enforcement activities with delivery tracking and follow-up
  • photo_metadata: Photo integrity tracking with hashes, GPS coordinates, retention policies, court-ready flags
  • audit_log: Immutable audit trail for all data changes (old values, new values, user, IP, timestamp)

Edge Functions (Serverless Backend)

  • process-field-scan: Unified scan processing (ALPR → compliance check → breach detection → notifications)
  • recognize-plate: Plate Recognizer API wrapper with NZ optimization
  • analyze-vehicle-photo: OnSpace AI integration for vehicle details enrichment
  • import-historical-data: AI-powered batch import with zone matching
  • cleanup-and-recalculate: Background compliance recalculation engine
  • generate-incident-pdf: Court-ready PDF generation with evidence photos and metadata
  • monitor-officer-welfare: Automated welfare check monitoring and escalation
  • send-push-notification: Mobile push notification delivery

🔄 Operational Workflows

Daily Field Operations Workflow

Morning Briefing: Admin creates patrols for the day, assigns zones and officers
Patrol Check-In: Officer logs into Field Portal, selects zone, checks in with GPS verification
Vehicle Scanning: Officer uses Scan or Zoom Scan mode to capture vehicle plates (ALPR automatic recognition or manual entry)
Automatic Processing: System evaluates compliance (nights stayed, consecutive days, self-contained status, homeless exemption)
Enforcement Decision:
• Officer-First Workflow: Officer immediately issues warning/notice if breach detected
• Admin-First Workflow: Officer records breach advisory → Admin reviews → Approves enforcement
Evidence Collection: Officer adds photos, notes, GPS coordinates to incident if H&S issue or serious breach
Sync & Reporting: All data syncs to cloud, Admin sees real-time dashboard updates, Leadership packs generated for council meetings

Investigation Job Workflow

Job Creation: Admin creates investigation job (e.g., "Homeless Occupation - Glendhu Bay Parking Area")
Assignment: Admin assigns to field officer with briefing notes, GPS location, priority level
Field Visit: Officer arrives on site, enables investigation mode (welfare monitoring paused), documents findings
Evidence Collection: Officer takes GPS-tagged photos (structures, vehicles, hazards), records persons contacted, makes recommendations
Completion: Officer submits findings report, Admin reviews, marks follow-up actions if needed

Compliance Recalculation Workflow

Trigger Event: Admin changes zone rules (e.g., reduce consecutive nights from 3 to 2)
Scope Selection: Admin selects recalculation scope (single zone, multiple zones, organization-wide, date range)
Background Processing: Edge function recalculates all affected observations using new matrix version
Drift Detection: System identifies observations that changed compliance status (compliant → non-compliant or vice versa)
Breach Alerts: New breaches auto-generate alerts, Admin reviews drift events for audit purposes

⚠️ Current System Limitations

Known Gaps (Under Development) These features are advertised in earlier marketing materials but not yet fully implemented:
  • GPS Photo Watermarking: Photos are stored with GPS metadata in database but do NOT have visible GPS/timestamp overlays on the image itself. Court-ready visual watermarking is planned for next release.
  • Offline Scanning with Auto-Sync: Offline queue UI exists, but IndexedDB storage and Background Sync API integration are not complete. Officers must have network connection to submit scans.
  • Real-Time Streaming Updates: Most dashboards require manual refresh. True real-time WebSocket subscriptions are only active for officer GPS tracking, not analytics/compliance data.
  • Load Testing Verification: System has not been tested with 100,000+ observations. Performance at scale is unverified.

🛠️ Support & Maintenance

System Administration

  • Master Admin Responsibilities: Monitor system health, run data integrity checks, manage user accounts across organizations, resolve escalated issues
  • Organization Admin Responsibilities: Create users, configure zones, review compliance, manage enforcement workflows
  • Help Documentation: Built-in help system in Admin Portal with feature guides and troubleshooting steps

Data Backup & Recovery

  • Supabase automatic daily backups (7-day retention)
  • Point-in-time recovery available for last 7 days
  • Emergency data recovery tools for Master admins (restore deleted records, resolve inconsistencies)
  • Audit log retention: Permanent (all changes logged with old/new values)

Security & Privacy

  • HTTPS encryption for all data transmission
  • Row-level security (RLS) ensures organizational data isolation
  • Photo retention policies enforce automatic cleanup (90 days standard, permanent for court-ready)
  • Audit logging tracks all user actions (IP address, user agent, timestamps)
  • Privacy controls for data export and deletion
