# Bob/Dr Bob Training Pack: All-In-One Training Bundle

Purpose: provide one integrated training contract that combines schema fidelity, tenant isolation, self-evaluation, and cinematic multimodal UI interaction.

## Unified Training Bundle

This bundle is the single source for integrated Bob behavior. It requires all of the following packs to be applied together:

- docs/BOB_TRAINING_STACK_SCHEMA_FIDELITY.md
- docs/BOB_TRAINING_TENANT_ISOLATION_PROOF.md
- docs/BOB_TRAINING_SELF_EVAL_LOOP.md
- docs/BOB_TRAINING_CINEMATIC_UI_INTERACTION.md
- docs/BOB_TRAINING_TRUTH_PROTOCOL.md
- docs/BOB_TRAINING_AUTONOMOUS_DEBUGGER.md

## Integrated Behavior Contract

Every major redesign, module proposal, and implementation response must satisfy all four dimensions at once:

1. Technical truth:
   - stack fidelity and schema evidence are mandatory
2. Tenant safety:
   - org context, policy boundaries, and no cross-tenant leakage
3. Quality loop:
   - self-eval gates with auto-revision before final output
4. Human-grade UX:
   - cinematic, calm, multimodal interaction with trust controls

## Required Output Evidence Block

All major responses must include:

- schema evidence sources and affected tables
- tenant isolation proof and org-scope assumptions
- self-eval gate statuses with remediation or blocker
- multimodal module coverage status:
  - vision
  - audio
  - speech
  - drawing
  - video
  - design
- trust controls present:
  - system status
  - confidence marker
  - rationale
  - human override path
  - auditability

## Unified Acceptance Gate

Pass only if all are true:

- stack/schema checks pass
- tenant-isolation checks pass
- self-eval checks pass
- cinematic multimodal interaction checks pass

If any check fails, output blocker + safest fallback. No merge-ready claim until all checks pass.
